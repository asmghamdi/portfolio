# Abdulrahman Alghamdi — Portfolio

Art Director at ALART and freelance designer. A static portfolio with selected projects and a collection of other artwork.

## GitHub Pages

In Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**.
All pages, styles, scripts, and optimized artwork are included. No build step or dependencies are required.

## Local preview

Run `python -m http.server 4173` from this folder, then open http://localhost:4173.
